# 孪晶调查与程序兼容

## 从线索到候选

结合晶胞度量、消光、强度、倒易空间/扫描情况、漏对称与已有模型检查。Flack 接近 0.5、高 R、椭球异常或软件提示都是调查起点，不能单独证明孪晶或迫使升为中心对称。

先检查原子类型、无序、吸收/标度与漏对称。记录当前指标基底，从适用的晶格关系提出候选律；同一父模型用独立分支比较，记录 BASF 及不确定度、相关性、ADP、残差和剩余异常。

| 数据支持 | 处理 |
|---|---|
| 可准确重叠的晶格分量与 HKLF4 强度 | 当前基底下论证 TWIN/BASF 后测试 |
| 非整比/部分重叠且有晶域/未合并观测记录 | 核对多晶域积分和 HKLF5 的重叠分组 |
| 只有已合并 HKL，晶域重叠信息丢失 | 描述限制，必要时回原始帧；改 HKLF 标签不能恢复信息 |

## PLATON 与 FCF

ADDSYM/TwinRotMat 用于候选调查。来源技能记录的是特定 macOS/PLATON 版本经验，不等于本机 Windows 构建已验收。

可在独立诊断目录用 `platon -m sample.res` 调查漏对称，或用 `platon -T1 sample.fcf` 调查 Fo/Fc 孪晶线索；当前程序帮助和输入要求优先。设置有限超时、关闭标准输入并保存 stdout/stderr，避免交互菜单无限输出；核对真正执行的是目标分析，超时/错误不算通过。

旧 PLATON 可能对新 SHELXL 的 FCF 权重字段处理不兼容。先读日志并确认 CIF、FCF、INS 来自同一轮；仅在诊断副本补入实际已记录的权重/波长等必要字段，保留来源与哈希。不了解当前权重公式或字段语法时停止，不从另一项目猜值。不将诊断副本替代原始存档 FCF。此次未移植来源技能的正则补丁器，也未宣称本机 TwinRotMat 已实际运行。

## 经官方指令核对的修正

- 反演矩阵本身含负号不表示输出退孪晶数据；TWIN 的分量数和符号按当前手册解释。退孪晶/导出若任务需要，按版本与实际输出设计独立步骤，不作为所有孪晶模型的固定必做项。
- SWAT 用于弥散溶剂模型，不能当作通用孪晶/吸收修正。
- BASF 接近边界或 0.5 时需结合不确定度和模型可辨识性调查，不自动删律或换空间群。
- HKLF5 与 HKLF4/TWIN 是不同输入协议，不能只靠改标签获得多分量信息。

依据：[SHELXL 指令](https://shelx.uni-goettingen.de/shelxl_html.php)。详细的 H、HKLF/溶剂依赖继续使用[已有参考](hydrogen-twin-solvent-cases.md)。
