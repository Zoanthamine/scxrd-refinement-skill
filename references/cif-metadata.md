# CIF 元数据和验证范围

信息来自当前采集/积分/吸收校正记录、配套 metacif、原始 CIF 或明确用户确认；来源矛盾时记录冲突，不按品牌猜软件，不将采集软件当仪器型号。

| 信息 | 证据要求 |
|---|---|
| 波长/辐射/温度 | 当前实验记录，交叉核对 CELL/CIF |
| 尺寸/颜色/形状 | 实测或确认记录，尺寸正确排序 |
| 仪器/光源/检测器/扫描 | 当前设备和采集记录 |
| 吸收校正/Tmin/Tmax | 实际处理日志，出现 SADABS 字样不能自动改 none |
| 晶胞反射数/θ 范围/误差 | 原始晶胞测定，不能用精修反射数冒充 |
| 组成/式量/Z/密度 | 占有率、特殊位置、离子和溶剂核对 |
| 构型来源/软件版本 | 当前证据/实际日志，不沿用其他晶体 |

低透射率不当然错误，Tmin=Tmax 也不能只凭相等判错；核对定义、归一化和日志。未知用 `?`，不填看似真实的占位数值。

## prepare

需 Gemmi，仅处理一个明确结构 data block。
从显式 --metacif 填补未知标量实验字段，冲突保留原 CIF 并报告。--meta 是已核实字段的显式覆盖，调用者记录来源。
缺项保留 `?`，输出 .metadata.json。不自动搜邻近 metacif、不推化学式、不抄构型结论、不补合成路线。语法不合法则停止，不用正则“修好”未知文本。
这是元数据编辑工具，编辑后仍要检查一致性并重新验证。

## 验证

重还原时保留有来源的采集/样品字段，更新实际数据还原软件、吸收过程、晶胞测定和统计。绝对透射与相对经验吸收范围分别标注；从真实吸收分量提取，排除总体标度/衰减，并核验分量组合能复现实际校正。没有可靠分量定义或归一化依据时保留未知，不自动用全部 inverse_scale_factor 的极值填写 Tmin/Tmax。案例中的相对范围不推广为通用报告规则，见 [流程第15–16步](dials-to-olex2.md)。

本地 validate 只做有限检查，不完整覆盖坐标、空间群操作、组成、占有率、嵌入记录和复杂 loop。缺 Gemmi 时连语法检查也未完成，不能当全面通过。
在线报告绑定实际输入哈希、模式、日期。CIF-only 不等于结构因子验证；下载成功不等于验证成功；单次 Upload error 不能证明固定 100 KB 限制。
PLAT964 要核对实际权重、CIF 和内嵌 RES，不能用“接近下一轮建议权重”替代一致性检查。
VRF 写具体问题、证据位置、做过的对照、结果和局限；没有证据就待解决，不自动写“正常热运动”“真实氢键”“合成已知”“已解决”。

依据：[IUCr checkCIF 模式](https://checkcif.iucr.org/)、
[IUCr 数据要求](https://journals.iucr.org/e/services/cif/reqdata.html)。
