# 多次实践得到的可迁移经验

这里保留经历史报告/代码复核支持的方法经验，省去研究样品、坐标、反射、实验数值和身份字段。不是对历史样品重新作科学验证，也不向新样品传播旧结论。

| 实践中遇到的问题 | 改善方式 | 迁移边界 |
|---|---|---|
| 多份候选/旧报告混用 | 唯一当前候选指针、哈希、父版本和采用理由 | final名称和最小R不决定当前版本 |
| 晶胞理想化后缺实验依据 | 保存变换矩阵、原始测量及假设；不虚构误差 | 补字段消A不能验证候选空间群 |
| 相同分子式、不同连接或楔形关系 | 原子映射、键级/保护基/H检查 | 同组成不等于同结构；连接/相对/绝对构型分开 |
| 异常低角I/σ或弱点 | 原样保留基线，排除只做独立诊断分支 | 弱/负强度不是删除理由 |
| SHEL范围写反 | 检查Å界限和实际反射集 | 错误命令失败不证明一般截断有害 |
| 低残峰被用于否定溶剂 | 差图/空腔/电子数/结晶信息综合 | Dcalc自洽与小残峰不足以排除弥散溶剂 |
| H自由精修异常、大绝对结构σ | 检查价态、PART邻居、差图与异常散射 | 不把热运动/氢键/合成构型当自动解释 |
| 原始帧读取器计数不一致 | 独立读取器逐像素核对，局部修复先验证 | 格式可打开不等于正确；专用插件不跨样品默认用 |
| 联合索引失败、个别轮难索引 | 分轮索引，可靠先验救援，检查基底 | 已知群索引成功不独立证明该群 |
| 调复杂背景/吸收后局部R下降 | 同父版本单因素比较，联合方案实际测试 | R1强集合变化/σ回退可能解释下降 |
| 个别轮持续几何偏差 | 位置/图像与等价观测独立证据；比较局部与整轮排除 | 排除映射和信息损失必须记录 |
| 候选Tmin/Tmax缺失 | 从实际吸收分量单独提取，核验完整乘积 | 总inverse scale factor、理论SIZE和旧软件值不能冒充 |
| 权重摘要读到首轮shift | 读取最后循环，实际与建议WGHT分开 | 权重收敛不证明原子模型收敛 |
| 程序断盘/超时/交叉验证报错 | 记录失败并保留日志，停止依赖分支 | 不用旧输出或成功标度冒充失败步骤已验证 |
| 11_plot简化绘图不可靠 | 移除旧工具；由Olex2/PLATON输出正式图 | 图片好看不等于元素/ADP/概率正确 |
| 同步锁、建议尾部和迭代覆盖 | 临时运行、科学指令有序保留、每轮独立归档 | 输入include/ABIN须专门准备；不能静默丢未知指令 |
| checkCIF在线上传/回退 | 保存真实模式和提交哈希，完整读FCF验证段 | CIF-only、HTTP成功不等于结构因子验证 |

下一步由当前证据决定：数据问题回还原、模型问题回精修、报告问题回配套文件。无新证据不继续无目标“压R”。
