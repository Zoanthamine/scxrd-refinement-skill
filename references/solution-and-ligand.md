# 从输入盘点到初始结构与配体核对

## 1. 盘点与可执行范围

`python scripts/inventory_crystal_input.py <目录或ZIP>` 只读列文件并检查 SFRM TYPE，ZIP 不解压。输出样品衍射候选、校准/背景和未知三类；存在候选帧只说明值得继续调查，不证明扫描完整、解码/几何正确或可以重积分。其他探测器格式由相应读取器检查。

| 现有证据 | 可考虑的工作 | 尚不能声称 |
|---|---|---|
| 完整原始衍射序列和实验几何 | 解码、索引、积分、标度对照 | 仅凭文件扩展名就已具备正确还原 |
| 未合并积分观测和实验元数据 | 标度、吸收及观测一致性诊断 | 缺原始像素仍能改积分背景/峰形 |
| 已校正 HKL、可靠晶胞/组成 | SHELXT 初始解与 SHELXL/Olex2 精修 | 可以恢复已丢失的晶域重叠信息 |
| CIF/RES，没有配套强度 | 语法、几何、连接、ADP 和对称线索 | 得到新的实验精修 R 值 |

Bruker `.raw` 可能是积分观测，文件名本身不决定内容。SFRM 中的 ACTIVE MASK、INITIAL BACKGROUND、BACKGROUND 按校准数据处理；未知 TYPE 留为未知。缺少像素、晶胞、强度或外部 FAB 时，继续可做的诊断并列出缺项。

## 2. 初始结构与空间群竞争

确认元素/组成来源、晶胞/基底、消光及强度数据；有可靠模型时优先复现，从零解结构时配置 SHELXT。XPREP 不可用不阻断有证据支持的 SHELXT 路线。

按当前消光、晶格和化学提出有限候选，分别建立完整 INS/正确变换的 HKL 与独立工作目录。记录实际引擎、版本、命令、输入哈希、CFOM/初始 R 和后续模型检查；候选数量由证据决定。最终比较连接、位点对称、几何、ADP、差密度、漏对称及适用的绝对结构指标，不按初始 R 单项裁决。ADDSYM 提案需要化学和衍射核实。

先建立可靠原子及连接，再处理较弱/柔性片段；配合物先核对金属、供体及电荷。配位/电荷必需的物种应显式解释，弥散孔道贡献按[溶剂分支](hydrogen-twin-solvent-cases.md)处理。

## 3. 配体拓扑与参考几何

连接不清时查用户给的 MOL/SDF/MOL2、结构式或其他独立化学证据，足够明确后再给环、平面、键长与氢模型。不能把峰排列像环直接当作芳香环。

```text
python scripts/prepare_ligand.py ligand.mol reference.mol --report ligand.json
python scripts/prepare_ligand.py ligand.mol reference3d.mol --report reference3d.json --optimize
```

需要 RDKit；首条只规范化并报告拓扑。脚本报告来源哈希、组成、电荷、片段、手性标记和软件版本。SDF 多条记录须先明确选择；不自动跳过无效记录取“第一条能读的”。

显式 optimize 采用 ETKDGv3 和有完整参数的 MMFF94s/UFF；不收敛/缺参数则停止，不输出伪装成功的优化构象。多个不相连物种保留为拓扑线索，分别评估，不能按一个分子随机摆放后当配合物几何。

源文件、输出和报告互不覆盖。参考几何用于连接与合理限制的起点；晶体坐标仍须由衍射密度、精修及验证支持。RDKit 给出的手性反映输入模型，不是实验测定绝对构型的证据。

完成条件：输入证据层次明确，初始解和竞争模型有来源，当前连接/价态/氢及配位解释可检查；未解决的化学或衍射问题保留。
