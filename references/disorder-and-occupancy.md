# 无序、占有率与几何/ADP处理

触发：拉长椭球伴随可重复的局部差密度、互斥构象、混占位、穿过对称元素或两组分不足。教程线索：020、030、113–116、118–121，出处与修正见 [来源说明](tutorial-sources.md)。以下是建模决策，不是固定指令套餐。

## 1. 先决定是否需要分裂

1. 保存未分裂父模型，检查元素、价态、H、吸收/分辨率、漏对称和孪晶。大ADP或LST的split建议只提供线索。
2. 将差密度与当前骨架、键长、对称邻居一起查看；寻找能组成完整、合理替代构象的峰，而非把每个峰都转成原子。
3. 先建立数据支持的最简单组分数。拆分后占有率接近边界、位置重合、相关性很强或少数组分无密度支持时，回查是否过度建模。
4. 每个互斥组分加上共同部分，都应单独构成合理化学结构。空间/时间平均不能仅凭单温度ADP区分；降温是可测试假设，不保证消除无序。

完成条件：能说明每个组分的密度、连接、占有率关系及相对父模型的必要性。

## 2. 普通两组分：PART和自由变量

对同一完全占据位点的两种取向，可用一个自由变量q及其补数1−q。原子行SOF中的`21`/`-21`编码第2自由变量及补数，不代表占有率21或负的化学占有率。第1个FVAR值是整体尺度。

```text
FVAR <实际尺度> <q的起始值>
PART 1
<组分A原子记录，SOF引用第2自由变量>
PART 2
<组分B原子记录，SOF引用第2自由变量的补数>
PART 0
<接续的有序原子记录>
```

此段是示意，不能直接运行或覆盖已有FVAR。已有多个自由变量时分配实际空闲编号；原子类型、坐标和U使用当前证据。PART行若带SOF会覆盖随后原子SOF，须核查，避免原子行看似正确而实际占有率被覆盖。

Olex2中可在选定原子上用Disorder工具/`split`建立候选，再回读INS核对PART、FVAR、AFIX和占有率。共享有序原子通常留PART 0；其附着H可能因相邻构象不同而需要随组分处理。分别显示有序部分＋每一个PART检查连接；画面交叉键消失不等于模型已验证。

若是部分占据、脱溶剂或不同化学组分混占，先按组成/电荷/实验记录决定总占有率，不能机械设为1。

## 3. 三组分及更多组分

数据确有第三构象/位点且两组分不能解释时，为各组分设置PART和独立自由变量。起始占有率尽量满足已论证的总数，避免全部设0.5导致不合理起点。用SUMP时记录目标、系数、变量编号及标准不确定度。

`SUMP`是线性**restraint**，不是严格constraint。SOF总和受带权限制而可能有微小偏差；按当前化学、精度及收敛选择σ，不能单为让化学式显示整数不断减小σ。若需要精确总和，另设计正确的参数化并核实软件支持，不能把SUMP误写成精确恒等式。

完成条件：占有率合理且有不确定度、总组成/电荷一致，增组分改善密度解释而非仅降低R或使椭球好看。

## 4. 特殊位置与负PART

区分化学占有率、原子位点多重性和SHELXL的SOF编码。一般位置的21/−21关系不能不经换算照搬到特殊位置。

处理步骤：

1. 由当前空间群操作、位点稳定子及轨道检查需要多少对称相关位置；长出完整分子后确定哪些原子是等价副本，哪些是独立参数。
2. 分别核算每晶胞原子数、组成、Z/Z′和位点多重性，检查GUI化学占有率与文件SOF的换算。
3. 只有模型确需分子以低于位点对称的取向出现时，才考虑负PART。它会抑制自动特殊位置约束并改变与对称生成原子的连接，不能当作普通分组快捷键。
4. 回到不对称单元再核对原子清单；Grow/Fuse后的视觉重合不能作为自动删原子的唯一理由。
5. 在每种取向下检查几何、重叠和电子密度。固定0.5或1/12等比例须由当前对称/模型支持。

对称相关的12个取向/位置不等于“12重旋转轴”；普通三维周期晶体的旋转对称受晶体学限制。教程115中的相关表述不作通用结论。

## 5. 选择限制和约束

| 当前需要 | 可选工具 | 核查 |
|---|---|---|
| 有来源的目标键长 | DFIX | 元素/键级、目标来源和σ；不是硬性的±σ区间 |
| 通过1,3距离表达角度 | DANG | 当前两键长度和夹角；是距离限制，不是角度指令 |
| 合理对应距离相似 | SADI | 只对应相同化学环境，不强行相等不同键级 |
| 两构象几何相似 | SAME | 原子映射/顺序、组分间对应和适用范围 |
| 平面/刚性片段 | FLAT或适用AFIX | 平面有化学依据；环张力、翘曲和刚性假设另查 |
| 刚体键ADP关系 | RIGU/DELU | 指定合理范围，不能修复错误元素或漏对称 |
| 邻近原子ADP相似 | SIMU | 物理邻近和独立组分关系，避免无关原子一起限制 |
| 接近各向同性的ADP | ISOR | 仅有理由的局部原子，不为遮盖严重无序而全局添加 |
| 确需完全相同位置/ADP | EXYZ/EADP | 是严格约束，会减少独立信息；U相同不能直接按Ueq相近决定 |

σ是最小二乘附加观测的权重尺度，不是实测标准不确定度，也不是必定满足的硬边界。保留充分而最少的假设，逐项检查是否过约束。

若从两键r1、r2与夹角φ推导1,3目标距离：`d = sqrt(r1²+r2²−2 r1 r2 cosφ)`。核对单位和计算，使用独立的合理几何来源；四面体理想角不是实际THF等有环张力片段的通用目标。不得把教程中的排版错误带入DANG。

## 6. 接受与归档

与相同父模型、同一反射/权重协议比较：占有率及σ、相关性、ADP/NPD、差图、几何、参数/限制数和末轮shift/s.u.。接受后重新加/核对H、生成同轮CIF/FCF，在精修说明中报告无序部分、比例、约束/限制和依据。
